# FinanceFlow AI 🚀

[TR] AI Destekli Bütçe Yönetimi ve Ekstre Analizörü.  
[EN] AI-Powered Budget Management and Statement Analyzer.

---

## 🌟 Özellikler / Features

### 🇹🇷 Türkçe
- **AI Ekstre Analizi**: PDF kredi kartı ekstrelerinizi yükleyin, Gemini harcamalarınızı otomatik kategorize etsin.
- **Maaş Bordrosu Ayrıştırma**: Resmi maaş bordrolarından gelir verilerini akıllıca çeker.
- **Kişiselleştirilebilir AI**: "Bro", "Muhasebeci" veya "Minimalist" koçluk stilleri arasında geçiş yapın.
- **Yerel Öncelikli Mimari**: Tüm verileriniz tarayıcınızın yerel depolama alanında (LocalStorage) güvenle saklanır.
- **Dil Desteği (i18n)**: Türkçe ve İngilizce arayüz desteği.
- **PWA Desteği**: Android ve iOS cihazlara yüklenebilir, offline çalışma desteği sunar.

### 🇬🇧 English
- **AI Statement Analysis**: Upload PDF credit card statements, and Gemini automatically categorizes your expenses.
- **Payslip Parsing**: Intelligently extracts income data from official salary slips.
- **Customizable AI**: Switch between "Bro", "Accountant", or "Minimalist" coaching personalities.
- **Local-First Architecture**: All your data is securely stored in your browser's LocalStorage.
- **Multi-language (i18n)**: Full support for Turkish and English interfaces.
- **PWA Support**: Installable on Android and iOS devices with offline capabilities.

---

## 🛠 Teknoloji Yığını / Tech Stack
- **Frontend**: React 19, Vite.
- **Styling**: Tailwind CSS (Glassmorphic Design).
- **AI**: Google Gemini API via `@google/genai`.
- **Charts**: Recharts.
- **Storage**: Browser LocalStorage.

## 🚀 Kurulum / Setup

1.  **Bağımlılıkları Yükleyin / Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Uygulamayı Çalıştırın / Run App**:
    ```bash
    npm run dev
    ```

3.  **API Anahtarı Tanımlayın / Set API Key**:
    [TR] Uygulama açıldıktan sonra **Ayarlar (Settings)** kısmına gidin ve [Google AI Studio](https://aistudio.google.com/app/apikey) üzerinden aldığınız ücretsiz API anahtarını girin.  
    [EN] After launching, go to **Settings** and enter your free API key obtained from [Google AI Studio](https://aistudio.google.com/app/apikey).

4.  **Kullanmaya Başlayın / Get Started**:
    [TR] Ekstrenizi yükleyin ve AI analizinin keyfini çıkarın!  
    [EN] Upload your statement and enjoy the AI analysis!
